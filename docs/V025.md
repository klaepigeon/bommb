# LAST CALL 3: MEAT PARTY v0.2.5 / MURDERLAND (APK 3.2.0)

What changed since v0.2, and where it lives.

## Party foundation (v0.2.5 spec)
- **Board**: graph board (`board_graph.gd`) with branches, gates, district names; `board_rules.gd`
  handles path choices, shops, items, events, rule prompts, swaps, slides.
- **Economy**: Teeth + Dead Rats (`economy.gd`, `shop_manager.gd`, `shop.json`), items
  (`item_manager.gd`, `items.json`, three held), events (`events.json`), hidden rules for
  THE CALLER'S GAME mode (`rule_manager.gd`, `rules.json`), Caller's Awards and the finale
  (`award_manager.gd`, `victory_manager.gd`).
- **Match length / mode**: QUICK 10, STANDARD 15, EXTENDED 20, MARATHON 30 rounds; CLASSIC or
  THE CALLER'S GAME. Chosen in the lobby.
- **Saves**: the match checkpoints every round (`Saves` autoload); CONTINUE on the main menu
  resumes it offline with the same dice.
- **Facility**: free first-person walking away from the table (`facility.gd`, `facility.json`),
  with a return timer and Caller responses. **No chat anywhere** (tested).
- **Seven new minigames**, each with its own control (hold, swipe, timing ring, trace):
  FLOOR IS MEAT, HOOK LINE & SINKER, SPIN CYCLE, TUG OF WAR, THE CONTROLLER,
  LAST MAN BREATHING, DON'T PRESS IT.
- **UI**: party HUD (`hud.gd`, `party_ui.gd`), Titan One / Baloo 2 fonts (OFL), UI scale, button
  size, reduced effects, reduced gore, left-handed layout (`Ui` autoload).

## Addendum
- **Animation framework**: `BodyAnimator` clips (anticipation/action/impact/follow-through/
  recovery), meat puppets on the board and in ordinary minigames, full characters for special
  events; presentation modes MEAT_PUPPET / FULL_CHARACTER / CINEMATIC / CUSTOM.
- **Cutscenes** (`cutscene_manager.gd`): forced spectator scenes, once, target-only effects.
- **Results**: staged placement presentation with puppet reactions; Caller table animations.
- **ORGAN TRAIL**: 2v2 surgery special event (surgeon/patient, organs, complications, sabotage,
  modifiers). Never in the normal rotation: a surgery square or the Caller calls it.

## MURDERLAND
- **The venue**: the slaughterhouse as the robot's party (`party_venue.gd`): host stage,
  prize counter, buffet, arcade, escape-room door.
- **The board** (`murderland.json`, generated by `tools/make_murderland.py`): 7 districts,
  122 spaces, no crossing paths, the CONTROL ROOM spoke. Its own world, off the table, in a
  gritty industrial style: flat district grounds, steel walkways with hazard rails, outlined
  squares coloured by type, one accent colour per district (`murderland_board.gd`).
- **Control System** (`board_machines.gd`): signposts, floodgates, rotator, conveyors, the wheel,
  the death machine, the parade, the royal gate; changes are announced a round ahead.
- **Camera director** (`camera_director.gd`): prioritised shots with spring smoothing for
  the intro, turns, landings and minigames.
- **Arenas**: minigames play in 10 themed arenas away from the board (`arena_world.gd`).
- **Escape room**: 5 rooms off the hall (`escape_room.gd`, `data/hall/escape_rooms.json`);
  escaping is an ending.

Balance is untouched by design: all the numbers are first passes in JSON.
